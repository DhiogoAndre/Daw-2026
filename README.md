# Cardápio Digital

Projeto de um cardápio digital para lanchonete, desenvolvido como atividade de Desenvolvimento de Aplicações para Web.

## Funcionalidades

- Exibição de produtos, descrições e preços
- Navegação por categorias
- Destaque da categoria selecionada
- Layout responsivo
- Área reservada para o carrinho de pedidos

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Prettier

## Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta `cardapio-digital`.
3. Abra o arquivo `index.html` no navegador.

Também é possível usar a extensão **Live Server** do VS Code para executar o projeto localmente.

## Estrutura do projeto

```text
cardapio-digital/
├── index.html
└── assets/
    ├── css/
    │   └── style.css
    ├── img/
    └── js/
        └── script.js
```

# Digital Menu

A digital menu project for a snack bar, developed as part of a Web Application Development course.

## Features

- Product, description, and price display
- Category navigation
- Highlighted selected category
- Responsive layout
- Reserved area for the order cart

## Technologies

- HTML5
- CSS3
- JavaScript
- Prettier

## How to run

1. Clone or download this repository.
2. Open the `cardapio-digital` folder.
3. Open the `index.html` file in your browser.

You can also use the **Live Server** extension in VS Code to run the project locally.

## Project structure

```text
cardapio-digital/
├── index.html
└── assets/
    ├── css/
    │   └── style.css
    ├── img/
```
